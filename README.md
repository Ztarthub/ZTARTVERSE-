# ZTARTVERSE-
 Ztartverse es un metaverso basado en la Tierra real (al estilo Google Earth + GTA Online + ReadyPlayerMe) donde los usuarios:  Crean y personalizan avatares  Caminan por lugares reales en 3D  Interactúan con otros usuarios visibles cerca (modo AR)  Entran a tiendas, etc.  Pagan c ZtartCoin y reciben en Ztart Wallet  Usan su Ztartag como identidad
